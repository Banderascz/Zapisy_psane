## URI
- Uniform Resource Identifier = Jednotný identifikátor zdroje
- Obecný zápis
$$
 URI = URL + URN
$$
```
schéma:hierarchická část?dotaz#fragment
```
---
## URL
- Uniform Resource Locator = Jednotná adresa zdroje
- URL definuje protokol, kterým je možné ke zdroji přistupovat, adresu serveru a umístění zdroje na serveru
- Př.:
```
https://tools.ietf.org/html/rfc1918.html
```
