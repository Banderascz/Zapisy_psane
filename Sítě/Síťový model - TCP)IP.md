- Vrstevný a Hierarchický
- Má méně vrstev než ISO/OSI, 4 vrstvy, vrstvy se nečíslují u TCP/IP
- Vrstvy: 
	- [^1]Vrstva síťového rozhraní - je prázdná(nedefinovaná)
	- [^2]Internetová vrstva - Zajišťuje komunikace mezi sítěmi
	- [^3]Transportní vrstva - Komunikace mezi koncovými uzly,  [^4]spolehlivost (správné uspořádání bloků), u videa, zvuku,... se nemusí tolik řešit spolehlivost -> lepší propustnost za lehký šum
	- [^5]Aplikační vrstva - Poskytuje protokoly, které aplikace používají pro komunikaci po síti: HTTP, FTP,.... Řeší formáty dat, šifrování, kompresi, autentizaci(podle protokolu).

[^1]: Network Access Layer

[^2]: Internet Layer

[^3]: Transport Layer

[^4]: Možnost výběru mezi spolehlivostí a rychlostí

[^5]: Application Layer
